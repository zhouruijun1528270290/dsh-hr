# 本地 msy 题库连接器

本插件可以把用户已有的 msy 数据作为只读题库来源。数据源由用户在 Setup 中配置，插件包不包含任何题库、账号、Cookie 或个人目录。

## 配置

在 Setup 的“本地 msy 题库”卡片中，优先点击“选择题库”使用 DSH Desktop 官方目录选择桥；浏览器 Web 端没有系统目录桥时，可展开“高级设置”手动填写目录。也可显式点击“自动识别 / 重新扫描”尝试候选目录；挂载页面不会自动扫盘。取消系统选择器不会清空当前设置。

目标目录包含以下文件：

```text
MSY_DIR/
  data/
    questions.ndjson
    answers-cache/       # 可选
  resume-bank.mjs        # 可选；只接受纯字面量导出
```

目录保存于 `~/.dsh/data/hr-interview/settings.json`。空目录设置表示关闭该来源；旧动态模式和精选题库仍可独立使用。

## 首版范围

- `questions.ndjson`：按版本化 Agent 标签白名单与 OFF_STACK 规则筛选；不会把全部岗位题无差别导入。
- `answers-cache/*.md`：只机械提取“回答重点”的最多 3 条要点；没有缓存不阻塞。
- `resume-bank.mjs`：只用受限字面量解析器读取 `RESUME_BANK`，不 import、不执行该脚本。
- `mock.mjs`：暂不接入；等待纯 JSON 导出。

所有 `.mjs` 都不会被插件 import 或通过子进程执行。插件不读取 `.mianshiya-cookie`，不调用 harvest，不联网补题。

## 存储与来源隔离

- 精选包：`market_questions.seed_source = 1`
- msy NDJSON：`seed_source = 2`
- 本地简历题：`seed_source = 3`

三类分别同步、分别清理。同步状态在 `market-sources.json`，数据库仍为 `market.sqlite`。失败时保留上次成功导入的数据并降级；空文件或异常骤减不会清空旧数据，也不会把被拒的收缩误记为已导入。

如果确实要接受一次超过 50% 的主动删题：先确保没有准备或面试写入任务，备份后删除 `market.sqlite`，下次准备会按当前文件重建精选包和外部域；删除前仍保留一份备份。

`profileKey` 仍只描述材料、时长与分类版本。单条题目的 `sourceRevision` 会进入 `planKey`，所以题库内容变化能在下一次准备时生成新提纲；已经生成或开始的面试继续使用冻结快照。

## 隐私与内容边界

- 不修改、删除或写回 msy 目录。
- 不把题目答案全文送入 Live prompt。
- 不把来源绝对路径写入 preparation 或模型输入。
- 题库数据不进入插件 tgz；公开来源链接仅指向原题页面。
- 普通岗位使用 shared 精选包，并可按 role/JD 关键词选用相关的本地简历深挖题；Agent 方向的 NDJSON 题不会混入普通岗位。
- 本地简历题要点可能含用户自己的仓库相对路径或符号，会随本地 preparation/session 保存；Live prompt 只发送公开题干，不发送这些要点或 msyDir 绝对路径。

## 故障提示

Setup 与提纲会显示来源数量及有限降级原因。目录缺失、文件过大、坏行过多、简历题包含可执行语法时，精选题库仍可使用。保存目录或显式重新扫描会读取数据源；开始面试不会重新抓取或同步。

普通“准备面试”在材料、时长和题库不变时复用确定性提纲。已有匹配提纲时点击“换一批题”，会优先选择尚未进入当前提纲的候选，并显示实际换题数量；可换候选不足时保留原提纲并明确提示，不制造重复准备记录。已开始的面试继续使用原冻结快照。
